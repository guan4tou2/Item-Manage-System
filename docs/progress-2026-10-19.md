## 七、流程備忘（本專案慣例）

每個 phase 的固定節奏：

1. 寫計畫（`docs/plans/YYYY-MM-DD-phaseN-*.md`，含 D1–Dn 決策、TDD 任務、Final Verification 空表）→ commit main
2. 建 worktree（複製 `.env`）→ `pnpm install --prefer-offline`＋`uv sync --extra test` → session 移入
3. 逐 task TDD（RED → GREEN）→ 每 task 一個 Conventional Commit（繁中 body）
4. 全套驗證：API pytest／Web vitest＋typecheck／api-types 零 diff／migration up-down-up／e2e／視覺走查 1440×900＋390×844
5. ff merge main → 收尾（CHANGELOG alpha.N、`docs/v2-roadmap.md`、計畫 Final Verification 填實測）→ 清理 worktree／分支／stack

### 編輯地雷（踩過的）

- `perl -pi -e` 取代含 `${...}` 的 template literal 會被展開成空字串（用 `edit` 工具或 node 腳本）
- jsdom：Radix Select 需 `scrollIntoView`／pointer capture mock；`URL.createObjectURL` 需 shim（已加在 `vitest.setup.ts`）
- i18n 逐鍵插入、勿整檔重寫；`zh-TW.json` 與 `en.json` 行數必須相同（有測試守門）
- e2e：`getByRole("alert")` 會撞 Next route announcer；檔案 input 是 `hidden`，用按鈕文案斷言
